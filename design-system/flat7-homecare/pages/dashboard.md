# Dashboard override

- Immersive architectural backdrop with a strong dark scrim for WCAG-readable content.
- Floating glass modules use `#0C1715` at 65% opacity, 24px radius, subtle white borders, and backdrop blur.
- Desktop uses horizontal pill navigation plus a compact shortcut rail; mobile keeps the global bottom navigation.
- Information hierarchy: greeting and household context first, then care completion, plant/AC status, bills, rooms, and weekly activity.
- Preserve 44px touch targets, visible focus states, and non-color status labels.
- Generated backdrop asset: `/public/dashboard-home.webp`, decorative with empty alt text.
